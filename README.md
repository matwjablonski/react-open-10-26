# Tworzenie aplikacji z użyciem React

Cześć! To repozytorium będzie naszą wspólną bazą podczas warsztatów. Zawiera
minimalny projekt startowy oraz workbook z zadaniami i miejscem na notatki.

## Zawartość

- [`my-books-app/`](./my-books-app/) — projekt Vite, React i TypeScript;
- [`materials/workbook.pdf`](./materials/workbook.pdf) — workbook uczestnika.

Wariant szkolenia: **redux, zustand, mobx**.

## Wymagania

- Node.js od 22.12 do 24.x (rekomendowany Node.js 24 przez `nvm use`);
- npm 10 lub 11;
- Git.

## Uruchomienie

```bash
git clone https://github.com/matwjablonski/react-open-10-26.git
cd react-open-10-26/my-books-app
npm ci
npm run dev
```

Po uruchomieniu rozpocznij od zadania 1 w workbooku. Projekt zawiera wyłącznie
konfigurację techniczną i neutralne dane wejściowe — rozwiązania zadań powstaną
w trakcie szkolenia.

## Przydatne polecenia

Uruchamiaj je z katalogu projektu:

```bash
cd react-open-10-26/my-books-app
npm run dev
npm run lint
npm run build
```
